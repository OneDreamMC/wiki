Cette page explique comment rejoindre One Dream : la version de Minecraft à installer, comment ajouter le serveur
dans votre client et les réglages à connaître pour la première connexion.

## Version de Minecraft

One Dream est un serveur **Java Edition** en version **26.1.2**. Lancez votre launcher, choisissez cette version dans
la liste des installations, puis jouez.

> [!IMPORTANT]
> Une version trop ancienne ou trop récente vous empêche de vous connecter. Vérifiez toujours la version affichée
> sur [le site](https://one-dream.fr) avant de lancer le jeu.

## Ajouter le serveur

L'adresse de connexion est dévoilée sur le site officiel et annoncée sur le Discord au moment de l'ouverture. Le wiki
ne l'affiche pas, pour éviter de diffuser une adresse périmée.

1. Ouvrez Minecraft et allez dans le menu **Multijoueur**.
2. Cliquez sur **Ajouter un serveur**.
3. Donnez-lui un nom, par exemple « One Dream », et collez l'adresse relevée sur le site.
4. Cliquez sur **Terminé**, puis sélectionnez le serveur et cliquez sur **Rejoindre**.

L'adresse est disponible ici :

- sur le site officiel : [one-dream.fr](https://one-dream.fr) ;
- sur le Discord officiel : [discord.gg/RjYBUUKYFg](https://discord.gg/RjYBUUKYFg), où les annonces et le support
  sont publiés.

## Le pack de ressources

Le serveur utilise un **pack de ressources** : il ajoute les textures, les sons et les menus de One Dream. À la
première connexion, le jeu vous propose de l'accepter. Vous devez l'**accepter pour entrer dans le monde** : le
message affiché en jeu le précise.

Le téléchargement prend quelques dizaines de secondes. Si vous l'avez refusé par erreur, déconnectez-vous puis
reconnectez-vous : la proposition revient à chaque connexion.

## En cas de problème

<details>
<summary>Le message « Version non compatible » ou « Outdated client » s'affiche</summary>

Votre version de Minecraft ne correspond pas à celle du serveur. Retournez dans le launcher, ouvrez l'onglet
**Installations**, créez ou modifiez une installation pour qu'elle utilise la version indiquée sur le site, puis
relancez le jeu.

</details>

<details>
<summary>Le jeu reste bloqué sur « Connexion au serveur »</summary>

Vérifiez d'abord que le serveur est bien ouvert (annonces sur le Discord). Si l'adresse est correcte et le serveur
ouvert, patientez quelques minutes : les files d'attente sont possibles lors des fortes affluences. Le problème
persiste ? Ouvrez un ticket sur le [Discord](https://discord.gg/RjYBUUKYFg).

</details>

<details>
<summary>Le pack de ressources boucle sur le téléchargement</summary>

Quittez le serveur, relancez le jeu, puis reconnectez-vous. Une connexion instable interrompt parfois le
téléchargement. Si le blocage continue, ouvrez un ticket sur le Discord.

</details>

Une fois connecté, suivez [les instructions pour créer votre île](creer-son-ile.md).
